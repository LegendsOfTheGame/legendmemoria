Plugins

All our Dalamud plugins for Final Fantasy XIV. Each plugin has its own repository URL. Our plugins are not in the official Dalamud plugin list.

How to install a plugin from a custom repository
  1. In the game, type /xlsettings to open the Dalamud settings.
  2. Select the Experimental tab.
  3. Find Custom Plugin Repositories. Paste the repository URL of the plugin into the empty field.
  4. Select the + button, then select Save and Close.
  5. Type /xlplugins. Find the plugin by name and select Install.

CAUTION: Plugins from custom repositories do not get a review from the Dalamud team. Add only repositories that you trust.
