Time Memoria

Live

Final Fantasy XIV · Dalamud plugin

Quest pacing for your adventure. Time Memoria records when you complete quests and shows how your time spreads across the story. It only describes your pace. It does not rank or judge it.

To install, add this URL to Custom Plugin Repositories in the Dalamud settings:

https://raw.githubusercontent.com/LegendsOfTheGame/TimeMemoriaV3/main/repo.json

About the studio

Legends of the Game is a small, independent studio. We build tools that we use ourselves, and we share them with everyone for free.

Many games ask you to remember a lot: which quests you finished, which rewards you collected, and what resets this week. Our tools keep that record for you, so that you can play instead of keeping notes.

You can support the work on Ko-fi. To see what we build next, read the public roadmap. To learn how we build our tools, read How we work.

  • Your data stays with you

    Our web apps keep your data in your browser. There is no account to make.

  • Free to use

    Every tool on this page is free. Support is optional.

  • Open source

    The source code is public on GitHub.
